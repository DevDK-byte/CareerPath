# 🚀 CareerPath

> **Navigate Your Career. Discover Your Opportunities.**

CareerPath is an AI-powered career guidance and placement platform designed to bridge the gap between students, career mentors, recruiters, and administrators. It provides personalized career recommendations, mentorship opportunities, resume building, and an integrated job portal within a single application.

---

## 📌 Overview

CareerPath helps students make informed career decisions by combining career assessment, resume management, job searching, and mentorship into one easy-to-use platform.

The system supports four user roles:

- 🎓 Student
- 👨‍🏫 Career Mentor
- 🏢 Recruiter
- 👨‍💼 Administrator

Each role has dedicated features while sharing a common, user-friendly interface.
